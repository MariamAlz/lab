Bad redaction finder.

A black box drawn over text in a PDF often hides nothing. The words are still in the file, and anyone can copy them out. Pixelating or blurring a screenshot can also be undone for short things like account numbers. Check your file here before you share it, so you know the hidden part is really gone.

How to redact properly
  • Use a real redact tool. In Acrobat: Tools › Redact › Mark for Redaction, then Apply, then Sanitize Document. Marking alone removes nothing.
  • Or delete, then cover. Delete or retype the private words in the original (Word, Excel) first, then make the PDF. A box drawn in Word over text doesn't remove it.
  • Or flatten. Print to an image, or export pages as images, then make a PDF from those. The text layer is gone. Run this check again afterwards.
  • For screenshots, use a solid box. Fill the area with one solid colour at 100% opacity. Don't use blur, pixelate, or a highlighter set to black at less than full strength.
  • Crop instead when you can. The safest pixels are the ones not in the file.
  • Check what else is in the file: names, comments and old versions. The document leak check covers those.

Why black boxes fail. A PDF page is a list of drawing steps: "write these letters here", "fill a black rectangle there". A box is just one more step drawn on top. Copy and paste, search, or any text tool reads the letters underneath. This page looks for dark rectangles in those drawing steps and checks which letters sit under them.

Why pixelation fails. Pixelating replaces each block with its average colour. For a short number there are only so many possibilities. An attacker renders every candidate in the same font, pixelates it the same way, and picks the one that matches. Tools that do this automatically are freely available.
