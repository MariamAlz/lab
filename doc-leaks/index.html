Document leak check.

Office files and PDFs carry more than the words on the page. Author names, deleted text in tracked changes, comments, hidden sheets, speaker notes, file paths from your computer and earlier saved versions can all travel with them. Check a file here before you send it, and see how to fix each problem.

The built-in fix
  • Word, Excel, PowerPoint (Windows): File › Info › Check for Issues › Inspect Document. Tick everything, Inspect, then Remove All for each item you don't need.
  • Office for Mac: Review › Protect › Protect Document, then tick "Remove personal information from this file on save". Accept tracked changes and delete comments yourself.
  • Acrobat: Tools › Redact › Sanitize Document (or Remove Hidden Information). This also drops earlier saved versions.
  • No Acrobat: Print to PDF makes a fresh file with only what is visible. Links and form fields are lost.
  • Sending to someone who only needs to read it? Send a PDF made from the final, accepted version.

How it works. A .docx, .xlsx or .pptx file is really a zip folder of XML files. Deleted text in tracked changes sits in a w:delText tag, and the author's name is written next to every change. This page unzips the file in your browser and reads those tags directly.

Earlier versions in PDFs. When a PDF is edited and saved quickly, the changes are added to the end of the file and the old version stays in front of them. Each save ends with a %%EOF marker. More than one marker usually means older content can be recovered.
