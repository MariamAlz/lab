Secret link.

Need to send a Wi-Fi password, a door code or a bank detail? Pasting it into a chat leaves it in that chat forever. This locks the note with AES-256 encryption on your device and packs it into a link. Only someone with the link (and the password, if you set one) can read it.

What is honest about this
  • Nothing is uploaded. The note and key live after the # in the link. Browsers never send that part to any server, including this site.
  • Expiry is checked, not enforced. The time limit is sealed into the encrypted data, so nobody can change it without breaking the lock, and this page refuses to open it late. But whoever has the link still has the locked data and could decrypt it with their own code.
  • Burn after reading is only a local flag. The receiver's browser remembers it opened the note and refuses next time. A different browser or a private window can still open it. True one-time links need a server, and this page has none.
  • The link is the secret. It stays in chat history and browser history. Use a password or split key for anything serious, and change shared passwords afterwards.

    The note was decrypted on this device. Nothing was downloaded from or sent to a server. If you're asked to type a password or a bank PIN into a link like this, stop: a secret link only shows a note, it never asks for your details.

    How it works. Your browser makes a random 256-bit key and locks the note with AES-GCM, which also detects any change to the locked data. With a password, the key is instead stretched from the password with PBKDF2 (600,000 rounds of SHA-256 with a random salt), so each guess costs an attacker real time. The locked note goes into the link after #c=, and the key after #k=. Everything after # stays in the browser.
