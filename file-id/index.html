      How it works
      
Most file formats start with a fixed signature, called a magic number. Every PDF begins with %PDF, every Windows program with MZ (the initials of Mark Zbikowski, who designed the format in the 1980s), and every ZIP with PK after Phil Katz. Word, Excel, PowerPoint, Android apps and Java programs are all ZIPs inside, so the page also reads the list of files packed within to tell them apart. It knows about 90 formats.

    

    

      If a file looks wrong
      
    
        
  • Don't open it. Delete it, or keep it closed until you've checked with the sender by phone.
    • 
        
  • At work, forward it to your IT or security team instead of opening it.
    • 
        
  • No match in a hash lookup doesn't mean it's safe. New malware is often unique.
    • 
        
  • Turn on "Show file extensions" on Windows (File Explorer, View) so names can't hide .exe.
