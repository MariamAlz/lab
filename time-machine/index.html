Website time machine.

The Internet Archive has been saving copies of the web since 1996. Type any site to see how often it was saved each year, then put two years side by side. Handy for nostalgia, for research, and for checking what a company's page said before it quietly changed.

Saves per year. Tap a bar to set the left view; tap again with Right selected to set the other.
