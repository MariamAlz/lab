Hide a message in a picture.

Every pixel's colour is three numbers from 0 to 255. Change the last bit of each and the picture looks identical, but those bits can spell out a secret. Hide text in a photo, lock it with a password if you like, and send the picture. Only someone who knows to look can read it.

Send the result as a file or document, not as a photo. WhatsApp, Instagram and most chat apps re-compress photos, which wipes the hidden bits. This hides a message from casual eyes; forensic tools can still tell that something is there. With a password the text itself stays unreadable even then.
