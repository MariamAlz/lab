Post time decoder.

Most big platforms hide the exact creation time inside every post's ID number. Paste a link and you get the time to the millisecond, in UTC and UAE time, even if the post was deleted, edited or screenshotted with the date cropped out. Fact-checkers use this to test when a "breaking" post really appeared.

How the time hides in the number

Big services make IDs on thousands of machines at once, so they can't just count 1, 2, 3. Twitter's 2010 answer, called Snowflake, puts the time in the first 41 bits of a 64-bit number, then the machine number, then a counter. Shift the ID right by 22 bits and you get milliseconds since Twitter's own start date, 4 November 2010. Discord, Instagram and LinkedIn copied the idea with their own start dates. Mastodon keeps the time in the top 48 bits, and TikTok keeps whole seconds in the top 32.

Before November 2010, tweets were numbered in order, so an ID like 20 (the first public tweet, March 2006) has no time inside it.

Good to know
  • The time is when the platform's server made the ID, which is when the post was published. Scheduled posts show the publish time, not when they were written.
  • Instagram links use a short code. It is decoded back into the media ID first.
  • Short links (vm.tiktok.com, t.co, lnkd.in) hide the ID. Open them first and copy the full address.
