Email header detective.

Every email carries a hidden travel log. Paste it here to see which servers handed it along, how long each step took, who really sent it, and whether the sender's domain vouched for it. The headers stay in your browser.

How do I get the headers?
  • Gmail: open the email, ⋮ menu → Show original → Copy to clipboard.
  • Outlook (web): ⋯ → View → View message source. Outlook (Windows): File → Properties → Internet headers.
  • Apple Mail: View → Message → All Headers (or Raw Source).
  • iPhone and Android apps usually can't show them. Open the email in a web browser instead.

Headers name servers, addresses and timestamps, not passwords. Still, they can include your own email address, so only share them with people you trust. Server-name lookups go to Cloudflare's DNS; nothing else leaves this page.
